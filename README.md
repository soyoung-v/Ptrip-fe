# Ptrip Frontend

공공데이터포털 한국관광공사 관광정보 API와 카카오맵을 활용한 여행지 검색 미니 프로젝트입니다.

사용자가 여행지 키워드를 입력하면 백엔드 API를 통해 관광 정보를 조회하고, 검색 결과를 카드 목록과 지도 마커로 확인할 수 있습니다.

## 프로젝트 소개

Ptrip은 외부 공공 API 연동과 지도 SDK 활용을 연습하기 위해 만든 포트폴리오용 미니 프로젝트입니다.

백엔드에서 한국관광공사 관광정보 API를 호출하고, 프론트에서는 검색 결과를 카카오맵과 함께 시각적으로 보여줍니다.

## 주요 기능

- 여행지 키워드 검색
- 검색 결과 카드 리스트 표시
- 카카오맵 지도 표시
- 검색 결과 위치 마커 표시
- 카드 클릭 시 해당 장소로 지도 이동
- 마커 클릭 시 장소명 인포윈도우 표시
- 카테고리 필터
- 상세보기 모달

## 기술 스택

- JavaScript

## 환경 변수 설정

프로젝트 루트에 `.env` 파일을 생성합니다.

~~~env
VITE_API_BASE_URL=http://localhost:8080
VITE_KAKAO_MAP_KEY=카카오_JavaScript_키
~~~

`.env` 파일은 민감정보가 포함될 수 있으므로 Git에 올리지 않습니다.

~~~bash

npm run dev
~~~

브라우저에서 아래 주소로 접속합니다.

~~~text

~~~

## 백엔드 실행 필요

프론트 실행 전, 백엔드 서버가 먼저 실행되어 있어야 합니다.

~~~text
http://localhost:8080
~~~

사용 API 예시:

~~~text
GET /api/tours/search?keyword=부산
GET /api/tours/{contentId}
~~~

## 화면 동작 흐름

~~~text
키워드 입력
→ 백엔드 검색 API 호출
→ 검색 결과 카드 리스트 표시
→ 좌표가 있는 결과를 카카오맵 마커로 표시
→ 카드 클릭 시 지도 이동
→ 상세보기 버튼 클릭 시 모달 표시
~~~

## 수동 테스트 방법

아래 키워드로 검색 기능을 확인할 수 있습니다.

~~~text
부산
제주
강릉
경주
대구
~~~

확인 항목:

- 검색 결과가 카드로 표시되는지
- 카테고리 필터가 동작하는지
- 지도에 마커가 표시되는지
- 카드 클릭 시 지도가 해당 위치로 이동하는지
- 마커 클릭 시 장소명이 표시되는지
- 상세보기 버튼 클릭 시 모달이 열리는지

## 구현 포인트

### 1. 백엔드 API 연동

프론트에서 공공 API를 직접 호출하지 않고, 백엔드 API를 통해 관광 정보를 조회합니다.

이를 통해 공공 API 인증키가 브라우저에 직접 노출되지 않도록 구성했습니다.

### 2. 카카오맵 SDK 동적 로딩

카카오맵 JavaScript SDK를 필요한 시점에 동적으로 로드하도록 구현했습니다.

~~~text
loadKakaoMap.js
~~~

### 3. 검색 결과와 지도 마커 동기화

검색 결과가 변경되면 기존 마커를 제거하고, 필터링된 결과를 기준으로 마커를 다시 표시합니다.

### 4. 카테고리 필터

검색 결과는 프론트에서 카테고리별로 필터링됩니다.

지원 카테고리:

~~~text
전체
관광지
문화시설
축제공연행사
여행코스
레포츠
숙박
쇼핑
음식점
~~~

## 주의 사항

- `.env` 파일은 Git에 포함하지 않습니다.
- `VITE_KAKAO_MAP_KEY`가 없으면 지도가 표시되지 않습니다.
- `VITE_API_BASE_URL`을 설정하지 않으면 기본값으로 `http://localhost:8080`을 사용합니다.
- 백엔드 서버가 실행 중이지 않으면 검색 기능이 동작하지 않습니다.
